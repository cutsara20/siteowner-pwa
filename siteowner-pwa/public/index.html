SiteOwner

Dashboard pemantauan tenaga kerja, K3, biaya upah, dan jadwal proyek untuk owner. Pengembangan dari WorkerKPI Ultra – Teknik Sipil USK.

Input Audit Harian –

Isi kondisi tiap pekerja. Kecepatan dihitung otomatis dari volume hasil dibanding target, bukan skor subjektif. Pilih kondisi tiap pekerja, perkiraan upah muncul di kanan atas tiap kartu pekerja. Sakit atau APD tidak lengkap: dilarang kerja. Untuk sakit pilih ada/tidaknya surat dokter, untuk APD pilih alasannya; besar upah mengikuti Pengaturan owner.

Laporan Harian untuk Owner



Pengaturan Proyek

Aturan dasar: absen tidak dibayar. Sakit atau APD tidak lengkap: dilarang bekerja (besar upah diatur di atas). Kurang sehat: boleh bekerja tanpa lembur. APD sebagian: boleh bekerja, kena potongan, tanpa bonus. Bonus butuh KPI minimal 85 dan APD lengkap. Hasil opname lapangan menjadi acuan progres.
Data tersimpan di server proyek. Rumus: progres harian = 2,5% × rasio pekerja fit × faktor KPI (0,8 / 1,0 / 1,1) + 0,05% per jam lembur.
